# Sample run (synthetic)

Every company, person, URL and number in this folder is made up. It exists so you can see what each stage writes and so
`uv run scripts/check_run.py examples/sample-run` has something to validate. Real runs go in `runs/`, which is git-ignored.

Stages 3, 5 and 7 are marked `skipped` here (no paid lookalikes, follower purchase or account search in the sample), and
stages 17-20 are `pending` because they happen after you send.
